Fitness Tracker

Project Description

This Fitness Tracker allows users to log their workouts by type, date, and duration and view weekly summaries to monitor and build healthy habits over time.

Features

  • Users can add, edit, and delete workouts
  • View workouts in a table (date, type, duration)
  • Display summaries of weekly progress
  • Earn achievement badges
  • Track calories burned and plan meals
  • Add user login and personalized dashboard
