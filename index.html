Fitness Tracker

Log workouts, track weekly progress, and build healthy habits.

Project Description

This Fitness Tracker allows users to log their workouts by type, date, and duration, view them in a table, and see weekly summaries to monitor and build healthy habits over time. All data is stored locally in the browser so it persists between visits on the same device.

Features

  • Add, edit, and delete workouts
  • View workouts in a table (date, type, duration, notes)
  • Weekly total minutes and workout count
  • Progress bar towards a 150-minute weekly goal
  • Simple achievement badges based on weekly activity
  • Data saved in the browser using localStorage (no login required)
